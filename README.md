# 紗希ちゃんノート

日向坂46・片山紗希さんのブログとトークの情報をまとめて見るアプリ。

- **ブログ**: GitHub Actions（`.github/workflows/fetch-saki-blog.yml`）が3時間ごとに公式ブログの一覧を取得し、`data/saki-blog.json` に追記します。保存するのはタイトル・日付・URL・冒頭120字の抜粋のみで、本文は公式サイトで読みます。
  - 初回は Actions タブ →「片山紗希ブログ取得」→ Run workflow で `pages` を `10` などにして過去分を取り込んでください。
  - メンバー番号の自動検出に失敗したら、公式サイトのブログ一覧URLの `ct=` の数字を入力して実行してください。
- **トーク**: 公式アプリの有料コンテンツなので自動取得はせず、自分でメモ（日時・種類・内容・タグ）を残す形式です。メモは端末の中（localStorage）にだけ保存されます。
- **要約・プロフィール**: `data/saki-summaries.json`（記事ごとの要約）と `data/saki-profile.json`（ブログから作ったプロフィール）は、Claude Code のチャットで「ブログまとめて」と頼んで作ったものです。自動では更新されないので、新しい記事は要約の代わりに冒頭の抜粋が表示されます。プロフィールの各項目には元記事へのリンクが付いています。
- **まとめ**: ブログとトークメモを1本のタイムラインに並べ、キーワード検索・タグ絞り込み・月別グラフで振り返れます。

## 公開のしかた

Settings → Pages で「Deploy from a branch」→ `main` / `(root)` を選ぶと、スマホから開けるURLができます。
